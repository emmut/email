# Codebase audit — 2026-11-19

## Scope and approach

Reviewed the React/TypeScript application, Rust/Tauri backend, manifests and
lockfiles, capabilities/CSP, SQLite storage, authentication, provider adapters,
offline replay, HTML rendering, packaging scripts, and CI workflows. This is a
source and dependency review, not a penetration test or a desktop runtime signoff.
No production accounts, infrastructure, or releases were changed.

The TS/TSX reference was [emmut/movies](https://github.com/emmut/movies), including
its CONTRIBUTING conventions, `back-target.ts`, `crew-members.ts`, and UI button
implementation (reference main commit `0f72e035a7f44b603d07918511a3884c0a1e2657`).
Applied named functions, braced conditionals, kebab-case naming, explicit control
flow, cohesive modules, and consistent single-quote formatting. The broad style
sweep accounts for much of the diff. Generated router output was regenerated by
the upgraded router plugin, rather than edited manually.

## Cleanup and dependency changes

- Extracted pure reply/forward draft construction into `src/lib/mail-drafts.ts`.
  Reply-all now normalizes the current user's address before comparing it.
- Removed duplicate OAuth callback, HTML response, and random-token helpers from
  account management; the OAuth module owns the shared implementation.
- Renamed the account context module to kebab-case and updated imports.
- Applied the reference's function/conditional style and consistent formatting
  across TS/TSX; added formatter scripts, a CI check, and CONTRIBUTING guidance.
- Simplified signature rendering and Vite configuration; replaced `__dirname`
  with `import.meta.dirname` for the current Vite loader.
- Upgraded the Vite/React plugin and Vitest together. Node requirements are
  explicit in package.json; CI's Node 22 setup must resolve at least 22.22.2.
- Moved Prettier and the Tailwind Vite plugin into development dependencies.
  Removed the local shadcn generator dependency. Its original 4.11.0 stylesheet
  is preserved under `src/styles/` with the upstream license; component
  generation already uses `pnpm dlx shadcn@latest` as documented in README.
- Pinned all TipTap packages to the same exact version, avoiding the mixed
  versions/export and type errors encountered during the upgrade.

### Reliability, privacy, and release hardening

- **Medium — Offline delivery semantics:** sends are retried after network errors,
  including ambiguous failures after a provider may already have accepted a send.
  This can duplicate delivery. Operations are dropped after ten non-network
  failures without a durable failed-operation interface. Add explicit delivery
  reconciliation and a recoverable failed-outbox state before promising reliable
  offline delivery. A queue already being replayed when an account is removed can
  also finish an in-flight request; deletion is not a provider-side cancellation.
- **Medium — Remote email content:** HTTPS images and inline styles remain
  permitted. Sanitization prevents script execution but does not prevent remote
  tracking. Add an explicit remote-content preference and sender exceptions.
- **Medium — macOS release trust:** configuration still uses ad-hoc signing and
  disables hardened runtime. Production signing/notarization and stable keychain
  identity require release credentials and platform acceptance testing.
- **Low — Native supply chain:** `scripts/fetch-sparkle.sh` downloads an archive
  over HTTPS without a pinned checksum. Pin verified release checksums before
  treating this build step as reproducible.
- **Low — Module size:** Gmail, account management, compose, and mail orchestration
  remain large. Further splits should follow ownership (transport, MIME parsing,
  sync, persistence), with integration coverage, rather than mechanically moving
  functions between files.
- **Low — Persisted JSON boundaries:** settings, signatures, rules and pending
  operations still rely on TypeScript casts/JSON.parse rather than full runtime
  schemas. Add versioned validation and explicit recovery for corrupt data.
- **Low — Bundle size:** the production build still reports chunks above 500 kB.
  Lazy-load editor/settings functionality as a separate performance change.

Deleting cache rows does not erase historical SQLite/WAL pages, backups, or data
already copied to another process. Existing on-disk mail remains unencrypted.
